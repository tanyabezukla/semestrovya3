# Семестровая работа № 3

## Тема
Реализация структуры данных **АВЛ-дерево** на языке Python.

## 1. Краткая историческая справка
АВЛ-дерево — это самобалансирующееся бинарное дерево поиска. Оно было предложено советскими математиками Г. М. Адельсон-Вельским и Е. М. Ландисом в 1962 году. Название «АВЛ» образовано от первых букв их фамилий.

Главная идея АВЛ-дерева состоит в том, что после вставки и удаления дерево автоматически балансируется. Благодаря этому его высота остается небольшой, а операции поиска, вставки и удаления выполняются быстро.

## 2. Принцип работы АВЛ-дерева
АВЛ-дерево является бинарным деревом поиска:

- все элементы в левом поддереве меньше значения в узле;
- все элементы в правом поддереве больше значения в узле;
- для каждого узла разница высот левого и правого поддерева не больше 1.

Эта разница называется **балансом узла**:

```text
balance = height(left) - height(right)
```

Если после вставки или удаления баланс становится больше 1 или меньше -1, дерево перестраивается с помощью поворотов.

## 3. Вставка
При вставке новый элемент сначала добавляется как в обычное бинарное дерево поиска. После этого для узлов на пути вверх пересчитывается высота и проверяется баланс.

Возможны 4 случая:

1. Левый левый случай — правый поворот.
2. Правый правый случай — левый поворот.
3. Левый правый случай — левый поворот для левого потомка, затем правый поворот.
4. Правый левый случай — правый поворот для правого потомка, затем левый поворот.

## 4. Поиск
Поиск выполняется так же, как в бинарном дереве поиска:

- если искомое значение равно текущему узлу, элемент найден;
- если значение меньше, переходим в левое поддерево;
- если значение больше, переходим в правое поддерево.

Так как дерево сбалансировано, поиск проходит не по всем элементам, а только по высоте дерева.

## 5. Удаление
Удаление также похоже на удаление из бинарного дерева поиска.

Возможны случаи:

1. У удаляемого узла нет потомков.
2. У удаляемого узла один потомок.
3. У удаляемого узла два потомка.

Если у узла два потомка, он заменяется минимальным элементом из правого поддерева. После удаления дерево снова балансируется.

## 6. Теоретическая сложность
Так как АВЛ-дерево поддерживает баланс, его высота имеет порядок `log n`.

| Операция | Сложность |
|---|---:|
| Вставка | O(log n) |
| Поиск | O(log n) |
| Удаление | O(log n) |

## 7. Практическая часть
В программе было сгенерировано 10 000 уникальных целых чисел.

Были выполнены следующие действия:

1. Поэлементная вставка 10 000 чисел в АВЛ-дерево.
2. Поиск 100 случайных элементов из массива.
3. Удаление 1000 случайных элементов из массива.

Для каждой операции измерялись:

- время выполнения алгоритма;
- количество шагов.

Измерялось только выполнение самих операций дерева.

## 9. Сравнение теории и практики
Для 10 000 элементов значение `log2(10000)` примерно равно 13.29. Практические результаты близки к этому значению:

- среднее число шагов при вставке: около 13.82;
- среднее число шагов при поиске: около 13.04;
- среднее число шагов при удалении: около 14.33.

Это подтверждает теоретическую сложность `O(log n)`. Небольшие отличия появляются из-за поворотов дерева, пересчета высот и особенностей конкретного набора случайных чисел.
